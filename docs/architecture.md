# Architecture

The ASP.NET Core API owns HTTP contracts, validation, rate limits and documentation. Core and Brazil are independent .NET 10 libraries. Infrastructure implements external adapters for ViaCEP postal addresses, IBGE locality lists, the BrasilAPI bank directory and BCB SGS economic observations. Lookup contracts and the supported indicator catalog belong to Brazil. API composition selects providers and manages bounded process-local caching. Calculation, validation and indicator catalog endpoints use local logic. Public data lookups require outbound HTTPS access to their respective providers.

The public playground uses React, TypeScript and Material UI. Vite builds static assets into the API's generated `wwwroot` directory; ASP.NET Core serves them at `/`. The frontend calls the same API origin and uses hash navigation for tool selection. Node.js and pnpm are build dependencies, not runtime services. Docker builds frontend and backend in separate stages. See the [frontend guide](frontend.md) for build and test instructions.
