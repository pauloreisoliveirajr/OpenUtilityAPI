# Architecture

The ASP.NET Core API owns HTTP contracts, validation, rate limits and documentation. Core and Brazil are independent .NET 10 libraries. Infrastructure implements external adapters for ViaCEP postal addresses, IBGE locality lists, the BrasilAPI bank directory and BCB SGS economic observations in v0.2 development. Lookup contracts and the supported indicator catalog belong to Brazil. API composition selects providers and manages bounded process-local caching. Calculation, validation and indicator catalog endpoints use local logic. Public data lookups require outbound HTTPS access to their respective providers.
